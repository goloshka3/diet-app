# 食事記録アプリ

ダイエット用の食事記録アプリ。食べたものを記録し、栄養の集計・不足の判定・
補う食材の提案までを目指す。

- 全体計画: `AIの作業場/ダイエットアプリ_制作ロードマップ.md`
- 今のステージ: **ステージ0**（食べたものを記録する）

## 動かし方

`index.html` を Web ブラウザで開くだけ。インストール不要。

- Windows: エクスプローラーで `index.html` をダブルクリック
- VS Code: 拡張機能「Live Server」を使うと、保存するたび自動で再読み込みされて便利

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `app.js` | 動き（記録の追加・削除・保存・表示） |

## データの保存先

ブラウザの `localStorage`。**そのブラウザの中だけ**に保存される。
別の端末・別のブラウザには引き継がれない。ブラウザのデータを消すと記録も消える。
（将来、書き出し／読み込み機能を追加予定）

## 技術

- HTML + CSS + JavaScript（素のまま。フレームワークなし）
- ビルド不要・サーバー不要
