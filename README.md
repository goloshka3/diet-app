# 食事記録アプリ

ダイエット用の食事記録アプリ。食べたものを記録し、栄養の集計・不足の判定・
補う食材の提案までを目指す。

- 全体計画: `AIの作業場/system/ダイエットアプリ_制作ロードマップ.md`
- 今の形（2026-09-30）: 写真で記録（AI が全栄養を埋める）／いつもの食べ物をタップで記録／
  全栄養の判定／ホーム画面から開けるアプリ（PWA）

## 動かし方

- **iPhone**: GitHub Pages の URL を Safari で開く → 共有ボタン →「ホーム画面に追加」。
  以後はホーム画面のアイコンから開く（全画面で開き、電波が無くても開ける）。
- **PC**: `index.html` をブラウザで開くだけ。VS Code の拡張機能「Live Server」を使うと、
  保存するたび自動で再読み込みされて便利。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `app.js` | 動き（記録・写真の AI 読み取り・いつもの食べ物・判定・バックアップ） |
| `foods.js` | 内蔵の食品データ（日本食品標準成分表） |
| `standards.js` | 食事摂取基準（目標値） |
| `suggestions.js` | 不足した栄養を補う食材の表 |
| `manifest.json` | ホーム画面に追加したときの名前・アイコン・色 |
| `sw.js` | サービスワーカー（電波が無くても開けるようにする） |
| `icons/` | アプリのアイコン |

## データの保存先

ブラウザの `localStorage`。**そのブラウザ（アプリ）の中だけ**に保存される。

- iPhone では、**Safari で開いたときと、ホーム画面のアイコンから開いたときで保存場所が別**。
  Safari で付けていた記録は、⚙️設定 →「書き出す」→ ホーム画面のアプリで「読み込む」で移す。
- 7日以上書き出していないと、画面の上に「今すぐ保存」の声かけが出る。
  iPhone では共有シートの「ファイルに保存」で iCloud Drive に置ける。

## 技術

- HTML + CSS + JavaScript（素のまま。フレームワークなし）
- ビルド不要・サーバー不要
- 写真の読み取りは Claude API（キーは ⚙️設定 で各自入力。ブラウザの中だけに保存）
